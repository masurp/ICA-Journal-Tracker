# Communication Science Journal Tracker

A lightweight, automatically updated dashboard tracking the most cited, trending, and latest papers from 25 communication science journals across six publishers.

**Live site:** [masurp.github.io/ICA-Journal-Tracker](https://masurp.github.io/ICA-Journal-Tracker/)

## Features

- **Most Cited / Trending toggle** — switch between all-time citation rankings and papers gaining traction in the last 2 years (ranked by citations per month; journals with too few trending papers open on All Time)
- **Latest** — most recently published articles per journal
- **Show more** — load papers 4 at a time; up to 50 per section
- **Cross-journal search** — searches titles, authors, topic keywords and abstracts across all journals; every word must match (use "quotes" for phrases), matches are highlighted, and results can be filtered by section, journal and year and sorted by relevance, citations or date
- **Topic chips** — 3–4 concise keywords generated by Claude AI from each paper's title and abstract; click to search
- **Keyword Trends** (overview & per journal):
  - *AI Keywords* — most frequent AI-generated topic keywords
  - *Topic Flow* — alluvial chart showing how topics shift across publication years
  - *Heatmap* — topic frequency across all journals side by side
  - *Topic Clusters* — keywords grouped by co-occurrence
- **Section filter** — choose which paper sections (Most Cited / Trending / Latest) feed the trend visualisations
- **Year range filter** — narrow the Topic Flow chart to a specific range of years
- **Shareable links** — every journal view and search (including its filters) has its own URL, and the browser's back/forward buttons work
- **RSS feeds** — subscribe to the newest papers in any feed reader: one feed for all journals ([`feeds/all.xml`](https://masurp.github.io/ICA-Journal-Tracker/feeds/all.xml)) and one per publisher (e.g. `feeds/ica.xml`), with authors, abstract and topic keywords; links are under *RSS feeds* in the site header

## How it works

A [GitHub Actions](.github/workflows/update_data.yml) workflow runs every **Monday at 06:00 UTC** and:

1. Queries the **[OpenAlex API](https://openalex.org/)** for the top 50 most cited, trending, and most recently published papers per journal, filtered by ISSN (records without a DOI are skipped). If a query fails, the previous week's list for that section is kept
2. Generates 3–4 concise topic keywords per paper via **Claude Haiku** (Anthropic API) using title + abstract. The model is shown the ~200 most common existing keywords and asked to reuse them, so the same topic gets the same label across papers; spelling variants are merged afterwards. Results are cached by DOI in `data/topic_cache.json`, so already-known papers are never re-tagged
3. Writes static JSON files to `data/` and RSS feeds to `feeds/` (150 newest papers each, from the *Latest* lists), and commits them back to `main`
4. GitHub Pages serves the updated site automatically

## Data sources & notes

- **Citation counts** — sourced from OpenAlex (`cited_by_count`), which aggregates across multiple sources and is more complete than Crossref alone
- **Most Cited** — ranked by total citation count (all time)
- **Trending** — papers published in the last 2 years with ≥2 citations, ranked by citations per month since publication (smoothed by 6 months so a 2-week-old paper with 2 citations doesn't outrank established ones)
- **Latest** — sorted by publication date
- **Topic keywords** — generated by Claude Haiku from each paper's title and abstract; cached per DOI so only new papers incur an API call on each weekly run. To re-tag everything (e.g. after changing the prompt), run the workflow manually with *Re-generate topic keywords* ticked
